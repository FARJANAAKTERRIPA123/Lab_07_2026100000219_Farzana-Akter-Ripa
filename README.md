## What is the Version Control?
Version Control is a system that track and manages change in files and projects over time . It helps us to see old version and work safely with others. 
## What is Git ?
Git is a free and open-source version control system.
## What is GitHub?
GitHub is a web-based platform that store Git  repositories in the cloud , allowing developers to work together on projects. 
## What is Git Bash? 
Git Bash is a Microsoft Windows application that provides a Linux/Unix-style command-line experience for running Git and terminal commands. 
## What are the main parts of GitHub?
The main parts of GitHub are its core version control elements and collaboration tools that help people build software together.
## What are the stages of GIT/GITHub? 
There are 3 stages of GIT Hub 
1. Working Directory
2. Staging Area
3. Local repository
